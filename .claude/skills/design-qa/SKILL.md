# DESIGN QA SKILL

Act as a Design QA Lead.

Your job is to catch implementation mistakes after the interface has been built.

# CHECKLIST

Inspect every page and major component.

## Spacing
Check:
- inconsistent padding
- inconsistent gaps
- cramped content
- excessive whitespace

## Typography
Check:
- font sizes
- weights
- line height
- line length
- hierarchy
- wrapping

## Alignment
Check:
- grid alignment
- text alignment
- section edges
- container widths
- inconsistent centering

## Components
Check:
- buttons
- cards
- navigation
- inputs
- badges
- panels
- icons

Ensure visual consistency.

## Responsive
Test:
- 1440px
- 1280px
- 1024px
- 768px
- 430px
- 390px

Check overflow and broken layouts.

## Interaction
Verify:
- hover
- focus
- press
- loading
- disabled
- active

## Motion
Check:
- timing
- easing
- consistency
- reduced-motion behavior
- animation overload

## 3D
Check:
- overlap with content
- text readability
- clipping
- mobile fallback
- performance

# FIX POLICY

Do not rewrite the entire design unless necessary.

Prefer targeted fixes.

Preserve:
- product intent
- content
- working functionality

Fix:
- hierarchy
- spacing
- readability
- usability
- responsiveness
- interaction clarity
- visual consistency

# FINAL PASS

Before completion, confirm:

- no horizontal overflow
- no broken text wrapping
- no unreadable contrast
- no inconsistent button styles
- no unnecessary cards
- no oversized empty areas
- no important content hidden behind effects
- no mobile layout failures
