# UI DESIGN RULES

Avoid predictable layouts.

Do not automatically create:

- centered hero
- heading
- paragraph
- two buttons
- three feature cards

unless that structure genuinely fits the product.

## Composition

Use intentional composition.

Consider:

- asymmetry
- overlapping layers
- foreground and background relationships
- strong focal points
- visual anchors
- negative space
- varied section rhythm
- spatial depth

## Typography

Typography must create hierarchy.

Clearly differentiate:

- display typography
- page titles
- section titles
- body text
- labels
- metadata
- navigation
- supporting text

Avoid giving everything similar visual weight.

## Cards

Do not turn every content block into a card.

Consider alternatives:

- open layouts
- split sections
- lists
- panels
- floating surfaces
- timelines
- data visualizations
- canvases
- spatial clusters

## Depth

Use depth intentionally through:

- blur
- shadow
- transparency
- perspective
- scale
- layering
- lighting

Avoid excessive glassmorphism.

## Visual System

Maintain consistency in:

- spacing
- radius
- typography
- grid
- shadows
- borders
- motion
- iconography

## Interaction States

Interactive components should support:

- default
- hover
- focus
- active
- selected
- loading
- disabled
- error
