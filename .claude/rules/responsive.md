# RESPONSIVE DESIGN RULES

Responsive design is not desktop scaling.

Design deliberately for:

- large desktop
- laptop
- tablet
- mobile

## Desktop

Use space for:

- hierarchy
- visual depth
- contextual information
- richer interaction

## Tablet

Reduce visual density.

Reconsider multi-column layouts.

Ensure touch targets remain usable.

## Mobile

Prioritize:

- primary task
- readability
- clear navigation
- thumb-friendly controls
- performance

Avoid simply stacking every desktop component vertically.

Remove unnecessary decorative elements when they interfere with usability.

3D and heavy visual effects must have simplified mobile fallbacks.
