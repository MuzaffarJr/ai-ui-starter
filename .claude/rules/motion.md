# MOTION DESIGN RULES

Motion must support usability or storytelling.

Use animation for:

- feedback
- hierarchy
- transitions
- content reveals
- directing attention
- spatial relationships
- state changes

Preferred technologies:

- Motion
- GSAP
- CSS transforms

Prefer animating:

- transform
- opacity
- filter

Avoid expensive layout animation unless necessary.

## Recommended Motion Patterns

Use when appropriate:

- staggered reveals
- spring interactions
- scroll-triggered transitions
- subtle parallax
- hover depth
- magnetic interactions
- shared-layout transitions
- masked reveals
- progressive section entrances

## Avoid

Do not use:

- constant bouncing
- excessive rotation
- aggressive zoom
- meaningless loops
- animation on every element
- long animations that delay interaction

Motion should feel responsive, controlled, and intentional.
